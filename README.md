# E-Commerce Sales, Customer Retention & Delivery Performance Analytics

## Project Overview
An end-to-end e-commerce analytics project using the Brazilian E-Commerce Public Dataset (Olist). The project analyzes sales performance, customer purchasing behavior, customer retention, and delivery operations.

## Tools & Technologies
- Python: Pandas, NumPy
- Jupyter Notebook: Data cleaning, EDA, feature engineering
- MySQL: Data storage and SQL analysis
- Power BI: Interactive dashboards and KPI reporting

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Feature engineering
5. MySQL database integration
6. SQL analysis using joins, CTEs, and window functions
7. Customer RFM and cohort analysis
8. Interactive Power BI dashboards

## Dashboard Pages
1. Executive Summary
2. Customer Analytics & RFM Segmentation
3. Delivery & Seller Performance

## Business Questions
- How are sales changing over time?
- Which product categories generate the most revenue?
- How many customers make repeat purchases?
- Which customer segments are most valuable?
- What percentage of delivered orders arrive late?
- Which sellers generate the highest product revenue?

## Dataset
Olist Brazilian E-Commerce Public Dataset from Kaggle.
